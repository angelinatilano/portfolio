AI Visibility Research Skill

Marketing Ops · GEO Systems

The Problem

A professional services firm wanted to understand how it was appearing, or not, in AI-generated answers across its service lines. No framework existed yet; "GEO" was barely an industry term. Running this research manually for one practice area took a full day.

The Approach

Built a Claude skill, an AI visibility research workflow that audits a service line page, generates the relevant AI-assistant query list, runs parallel live web research, synthesizes findings into a structured report, and produces a Word doc and optional slide outline from a single URL. Designed the methodology and prompt architecture, piloted it on one service line first.

The Outcome

3 hours saved per campaign. A repeatable GEO methodology any practice area can run. A framework built before the job title existed.

AI-Governed Component System

Systems Design · AI Workflows

The Problem

A marketing team needed custom, interactive components for WordPress landing pages, modals, card grids, expandable sections, without pulling in an external dev team for every request. AI code generation could produce components fast, but with no guardrails, output was inconsistent: off-brand colors, accessibility gaps, security anti-patterns, and code that broke inside the CMS's custom HTML block editor.

The Approach

Authored a rulebook, a single reference document codifying every constraint a block needs to satisfy: brand typography and color tokens, locked-down button components, a security checklist, WCAG AA accessibility requirements, and CMS-specific quirks. The rulebook doubles as a shared contract: fed to Claude at the start of every build, and handed to an outside dev team as documentation they can audit against.

The Outcome

Marketing can now generate production-ready, on-brand, accessible components directly through Claude, with the rulebook acting as a quality gate rather than relying on manual review. The standard scales cleanly and is legible enough for an external dev team to pick up without a briefing call. LinkedIn Takeover + Dashboard

Social Strategy · Data Visualization

The Problem

A B2B brand's LinkedIn was dormant, engagement flat at 6.41% (already above the ~2% industry average) with no growth trajectory, no content strategy, no data infrastructure, no way to show leadership impact.

The Approach

Took over the account with a defined strategy: consistent posting cadence, content pillars matched to the audience, copy written to drive engagement. Built an interactive dashboard alongside it, a visual tool that made the data legible to non-technical stakeholders. Every post measured, every decision documented.

The Outcome

6.41% → 17.7% engagement in 30 days, 8x industry average, achieved on an inherited account with no paid amplification. The dashboard became the artifact that made the case to leadership.

Event Workflow Claude Skill

AI Workflows · Content Strategy · Automation

The Problem

A multi-brand professional services firm hosts 3–4 events per week, depending on the season. Each one required manually producing a website event description, a LinkedIn caption, and a personalized outreach message to the featured professional, every time. At roughly 40 minutes per event, that adds up to 100–140 hours a year on repetitive production work.

The Approach

Built a Claude skill, a reusable, production-grade AI agent, that takes an event brief as input and outputs all three assets automatically, following the firm's brand voice and workflow rules. Wrote the skill definition, prompt architecture, and output logic from scratch, handling edge cases like public vs. private events, designed to run by anyone on the team without technical knowledge.

The Outcome

Runs weekly in production. Roughly 120 hours a year returned to the team. Zero external vendor cost. One tool, three assets, consistent brand voice, every time.
