AI-Governed Component System

Kaufman Rossin — Marketing Ops

The Problem

Kaufman Rossin's marketing team needed custom, interactive components for WordPress landing pages — modals, card grids, expandable sections — without pulling in an external dev team for every request. AI code generation could produce components fast, but with no guardrails, output was inconsistent: off-brand colors, accessibility gaps, security anti-patterns, and code that broke inside WordPress's Custom HTML block editor.

The Approach

Authored a rulebook — a single reference document codifying every constraint a block needs to satisfy: brand typography and color tokens, locked-down button components, a security checklist, WCAG AA accessibility requirements, and WordPress-specific quirks. The rulebook doubles as a shared contract: fed to Claude at the start of every build, and handed to the outside dev team as documentation they can audit against.

The Outcome

Marketing can now generate production-ready, on-brand, accessible components directly through Claude, with the rulebook acting as a quality gate rather than relying on manual review. The standard scales cleanly and is legible enough for an external dev team to pick up without a briefing call.

KR Event Workflow Claude Skill

Kaufman Rossin — Marketing Ops

The Problem

Kaufman Rossin hosts 11+ events per week across its brands. Each one required manually producing a website event description, a LinkedIn caption, and a personalized outreach message to the featured professional — every time. At roughly 40 minutes per event across 52 weeks, that's 382 hours a year on repetitive production work.

The Approach

Built a Claude skill — a reusable, production-grade AI agent — that takes an Asana event task as input and outputs all three assets automatically, following KR's brand voice and workflow rules. Wrote the skill definition, prompt architecture, and output logic from scratch, handling edge cases like public vs. private events, designed to run by anyone on the team without technical knowledge.

The Outcome

Runs weekly in production. 382 hours per year returned to the team. Zero external vendor cost. One tool, three assets, consistent brand voice — every time.
